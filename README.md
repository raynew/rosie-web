# Rosie H — Model Portfolio

A small static portfolio for model Rosie H. It features selected images and
profile details from her public PurplePort portfolio. Preview it locally with:

```bash
python3 -m http.server 8080
```

Then open <http://localhost:8080>.

## Customize

- Edit page copy and selected work in `index.html`.
- Update the profile, Instagram, and moodboard URLs in `js/config.js`.
- Change typography and colors in `css/style.css`.

Portfolio photographs link to their original PurplePort pages and load from
its public image CDN.
